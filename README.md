Gestion Restaurant – ASP.NET

A restaurant management web application built with ASP.NET Core and C#. It combines a responsive restaurant website with an admin dashboard to manage the restaurant's content and activity.

Project solution: Glovvo_Yassine_Touli.sln · Web project: SiteWeb

Features

Responsive public website for the restaurant (Bootstrap)
Admin dashboard (SB Admin 2 template) with tables and charts
Management of restaurant data (menu, orders, customers, ...)
Clean, mobile-friendly interface
Tech Stack
Layer	Technology
Backend	C#, ASP.NET Core
Database	Microsoft SQL Server
Frontend	HTML, CSS, JavaScript, Bootstrap
UI / Admin	SB Admin 2, Font Awesome, DataTables, Chart.js
IDE	Visual Studio

Getting Started
Prerequisites
Visual Studio 2022 with the ASP.NET and web development workload
.NET SDK (the version targeted by the project)
Microsoft SQL Server (Express edition or LocalDB is enough) and, optionally, SQL Server Management Studio (SSMS)
